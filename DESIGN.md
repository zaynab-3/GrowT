## 3. Layout Structure & Navigation

### A. Desktop Layout
*   **Fixed Sidebar:** On the left, occupying `256px`. Glassmorphic backdrop-blur effect. 
*   **Content Pane:** Top navbar showing active workspace/folder title, search input, and a green pulsing indicator for realtime syncing. Container padding is `32px`.

### B. Mobile Layout
*   **Bottom Navigation Bar:** Contains 4 primary navigation tabs (Dashboard, Folders, Tasks, Settings).

---

## 4. Reusable Component & Control Styles

*   **Buttons:** Solid violet backgrounds (`#5E3BDB`) with white bold text, rounded corners. Secondary buttons use transparent backgrounds and borders.
*   **Inputs:** Thin border (`#C9C4D7`), soft background tint, solid `#5E3BDB` highlight border on focus.
*   **Badge Indicators:** Used for task categories and workspace member counts. Rendered as pill shapes with desaturated color backgrounds.

---

## 5. Folder & Task Layout Patterns

### A. Folder Card
*   Grid layout with a horizontal header (folder name, type icon), description body, task progress indicator, tag pill, and utilities.

### B. Task Card
*   Vertical row showing a header (title, owner avatar, assignee selection), a text description, and a checklist builder.
*   Quick status switch controls.
